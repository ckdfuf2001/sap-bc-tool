SU01 분석 (A4H) — User Maintenance

분석일: 2026-09-09 · 시스템: A4H (localhost trial, 001/DEVELOPER) · 티코드: SU01 (User Maintenance)
프로그램: SAPMSUU0 / 패키지 SUSR · 탐색: erpl-adt CLI (= MCP adt_* 대응, 본 환경 MCP 미장착으로 fallback)

1. 실행 경로 요약

  1. SAPMSUU0 실행 → AUTHORITY_CHECK_TCODE('SU01'), 실패 시 LEAVE PROGRAM
  2. CALL FUNCTION 'SUID_IDENTITY_MAINT' (Remote-enabled 확인)
  3. lcl_maint_main 객체 생성 → gr_main->start()
  4. 초기 화면(50/51) → 메인 정비 화면(100, 1050/1051/1100) + 탭(LIF_MAINT_TAB)
  5. 저장 do_save → SUID_IDENTITY_SAVE_TO_DB → USR02 갱신. RFC 재현은 BAPI_USER_*

6. 권한 체크

실측: AUTHORITY_CHECK_TCODE('SU01'). 세부 오브젝트는 CL_SUID_TOOLS 경유 추정이나 원문 미확인. BAPI 경로 필요 권한: S_RFC, S_TABU_NAM(직접 접근 시), S_USER_GRP(미확인 표기).

7. RFC-only 재현 전략

BAPI 우선 + BAPI_TRANSACTION_COMMIT(WAIT=X)/실패 시 ROLLBACK, RETURN 전건 검사. 대량은 rfc_read_full. 불가: 탭 dynpro 검증·F4·CUA 메뉴 (GUI 전용).

9. 미확인/주의사항

  • dynpro 필드明细 (D020S/D021S RFC 불가)
  • 세부 AUTHORITY-CHECK 오브젝트 (CL_SUID_TOOLS 경유 추정)
  • BAPI 상세 구조는 표준 시그니처 기준 — 실호출 테스트는 tcode-to-python 단계에서 수행
